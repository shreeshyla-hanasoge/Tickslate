Examples

Small pages that each show one way to use Tickslate, with the same package names the README imports. Each one is a working page: open it, then view its source. All figures are made up.

Playground Widget gallery
  • Quick start

    The README's quick start: a metric, a chart and a card in a grid, with the layout saved by persistLayout.

  • Generic dashboard

    A dashboard with nothing to do with trading: metrics, charts and cards of slotted content, with no layout code.

  • Trading dashboard

    Every finance widget with a metric, a loss-limit gauge and a table of fills, on one saved grid that switches layout when the market opens and closes, fed by a seeded fake feed, with every action answered.

  • Bare install

    The smallest possible install: the elements entry alone, with no stylesheet and no web fonts.
