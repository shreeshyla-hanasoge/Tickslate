### Added

- Guides for server-side rendering: `docs/guide/ssr.md` (loading the elements in the browser only, the pre-upgrade CSS that reserves each tile's space, hydration and `persist`), with recipes for [Next.js](docs/guide/frameworks/nextjs.md) and [Nuxt](docs/guide/frameworks/nuxt.md).
- Working example apps in `examples/`: `vanilla-cdn` (one script tag), `react-vite`, `vue-vite` and `svelte-vite`. Each renders a grid with a metric, a chart, a card and Today's P&L, passes `data` as a property, listens to `ts-action` and saves its layout with `persist`.

### Changed

- The React recipe (`docs/guide/frameworks/react.md`) no longer says its behaviour is unverified: React 19 properties and the `onts-action` event form are confirmed, and the JSX typings now come from `tickslate/jsx`.

### Internal

- `scripts/test-consumers.mjs` (`npm run test:consumers`): packs `dist-lib/` (running `npm run release` first if it is missing), copies each example to a temp directory, installs the tarball and the framework dependencies from npm (network needed), builds it (the three framework examples type-check with `tsc`, `vue-tsc` and `svelte-check` first, through `tickslate/jsx`, `/vue` and `/svelte`), serves it on a free port in 5190-5199 and runs `examples/smoke.spec.mjs` in Chromium: the four widgets render figures, no tiles overlap, a tile activation reaches the host as `ts-action`, and a keyboard move in edit mode fires `ts-layout-change` and survives a reload. Temp directories are removed on every exit path. `TS_ONLY=react-vite,vue-vite` narrows a local run.
- CI: a separate `examples` job (`needs: build`) runs `npm ci`, `npm run release` and `npm run test:consumers` with Chromium installed. It rebuilds rather than downloading the build job's artifact, so the tarball it tests is its own.
- Deviations from RFC 0003 §24 and the story file list: the React example is `App.tsx` (not `App.jsx`) and the Vue and Svelte examples use TypeScript, so the typings entries are exercised by the build. Vite 8 is pinned in the examples because the current React and Svelte plugins require it; the repo's own Vite (5) is untouched.
- For the docs owner (README.md was not edited here): the README's framework list could link the new Next.js and Nuxt recipes and `docs/guide/ssr.md`, and could point at `examples/`. React corrections confirmed by running the example: (1) React 19 sets `data` as a property, as the recipe says; (2) `onts-action={handler}` does work in React 19.3, so "to be verified" is removed; (3) a boolean attribute takes a boolean in React 19 (`activatable` true), not `""` as the recipe said; (4) the hand-written `IntrinsicElements` declaration is replaced by `import type {} from 'tickslate/jsx'`. Edited in `docs/guide/frameworks/react.md` itself, since no one else owned it. Not run: React 18 (the ref-and-effect section is unchanged), `persistLayout` called from an effect, and Svelte 5's `onts-action` attribute (the Svelte example uses the typed `on:ts-action`; svelte-check rejects the other form with the shipped typings). The `vue.md` and `svelte.md` recipes' `.prop`, `bind:this` and `persist` claims were not contradicted by the examples.
