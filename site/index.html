Dashboards your users can rearrange.

Tickslate is a library of drop-in dashboard widgets: a grid people can drag and resize, and tiles for figures, charts, tables and cards, for any data. A finance set for trading apps is built in. It is plain HTML elements, so it works with any framework or none.

What is Tickslate?

A dashboard is a page of small tiles, each showing one thing: a number and how it moved, a trend, a list. Tickslate gives you those tiles ready-made, and a grid to put them in that each user can arrange for themselves. You hand each tile your data; it does the drawing.

  • A grid people can rearrange

    Seven tile sizes on a grid of four columns that becomes three on a tablet and two on a phone. Users long-press to edit, drag to move, pull a corner to resize, and undo a removal. One line saves their layout.

  • Widgets for any data

    A KPI tile with its change, trend and target; line, area and bar charts; a progress gauge; a sortable table; and a card that holds anything else, including a chart from another library.

  • A finance set built in

    Today's profit and loss, an equity curve with drawdown, exchange session clocks, a watchlist, open positions, a P&L calendar, edge stats and capital funding, all speaking the words a trading app uses.

  • Framework-free. Custom elements with no runtime dependencies. This site is plain HTML and ES modules too.
  • Themeable. Every colour, radius and font is a --ts-* CSS variable. Six presets ship with it.
  • Accessible. Keyboard editing, tiles that say what they show, and signs as well as colours on every gain and loss.

Install

With a bundler

npm install tickslate
import 'tickslate/elements'

That registers <ts-grid> and every widget. Each widget also has its own entry, such as tickslate/elements/metric, so you pay only for what you use.

With no build step

<script src="https://cdn.jsdelivr.net/npm/tickslate@__TICKSLATE_VERSION__/cdn/tickslate.iife.js"></script>

One script tag loads every element. The URL pins an exact version, so a new release never changes your page.

Built for trading apps

The finance widgets know what a trading screen needs: a sign and an arrow on every gain and loss, session times in the exchange's own zone, figures that update in place without moving the layout, and a header that says when the data has gone stale. These six run on the same made-up feed as the board above.

Want this as a page? The playground runs a full trading board with a schedule that swaps layouts at the market close, and its Copy HTML button gives you the page.

Accessible by default

  • Keyboard editing. Tab to a tile, Space to pick it up, the arrow keys to move it, Space to drop, and plus or minus to resize.
  • Tiles that say what they show. A screen reader hears “Users online, 18,420, up 4.1%”, not just “Users online”, and each chart states its result in words.
  • Never colour alone. Gains carry a plus sign and losses a true minus, each with an arrow, so the meaning survives any palette.
  • Forced colours and reduced motion. Boundaries, focus rings and chart lines stay visible in high-contrast modes, and nothing wiggles when motion is turned down.

Your theme, a few variables

Tiles read their look from --ts-* CSS variables, so matching your brand is a handful of lines, never a fork. Paper is the light theme and Graphite the dark one; data-theme="auto" follows the system.

:root {
  --ts-accent: #0b6bcb;
  --ts-radius: 6px;
  --ts-font-ui: 'Inter', system-ui, sans-serif;
}

Six presets ship as stylesheets: Neutral, Paper, Graphite, Calm, Signal and Terminal. Try one on the board at the top, or read the theming guide.
